# Help!

## Descrição

O desafio consiste em calcular o placar de uma competição de programação. É necessário descobrir quantos problemas foram resolvidos corretamente e calcular o tempo total, incluindo as penalidades por tentativas incorretas.

Cada tentativa incorreta de um problema que foi resolvido acrescenta 20 minutos ao tempo final.

## Lógica utilizada

Utilizei um dicionário para guardar a quantidade de tentativas incorretas de cada problema. Quando um problema é resolvido corretamente, somo o tempo da resolução e as penalidades ao total. Também conto quantos problemas foram resolvidos.

## Arquivos

- `help.py`: código em Python.
- `entrada.txt`: dados de entrada.
- `saida.txt`: resultados do programa.
