# Suco de Acerola

## Descrição

O desafio consiste em calcular quantos litros de suco cada amigo poderá tomar, considerando a quantidade de frutas colhidas e o número de amigos.

Cada fruta produz 50 ml de suco, que deve ser dividido igualmente entre todos.

## Lógica utilizada

Multipliquei a quantidade de frutas por 50 para encontrar o volume em mililitros. Depois, converti o resultado para litros e dividi pela quantidade de amigos. A resposta é exibida com duas casas decimais.

## Arquivos

- `suco.py`: código em Python.
- `entrada.txt`: dados de entrada.
- `saida.txt`: resultados do programa.
