# Fechem as portas!

## Descrição

O desafio consiste em descobrir quais portas de uma mansão estarão abertas depois que todos os descendentes trocarem o estado das portas cujos números são múltiplos de seus identificadores.

Todas as portas começam fechadas. Ao final, precisamos mostrar os números das portas que permanecem abertas, em ordem crescente.

## Lógica utilizada

Percebi que somente as portas que possuem números quadrados perfeitos ficam abertas. Por isso, o programa verifica os quadrados de 1 até o limite de N.

## Arquivos

- `portas.py`: código em Python.
- `entrada.txt`: dados de entrada.
- `saida.txt`: resultados do programa.
