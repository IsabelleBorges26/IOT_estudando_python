Lista de exercícios de Python desenvolvidos durante os estudos da linguagem.

## Tecnologias

- Python
- VS Code

## Exercícios

1. Média de três números
2. Conversor de temperatura
3. Identificação de número par ou ímpar
4. Cálculo de fatorial
5. Verificador de ano bissexto
6. Verificação de número positivo ou negativo
7. Comparação de dois números
8. Verificação de idade
9. Verificação de número par ou ímpar
10. Classificação de triângulos
11. Verificação de ano bissexto

## Desafios

Resolução de quatro desafios utilizando Python, com entrada e saída de dados por arquivos de texto.

1. **Fechem as portas!** — Identificação das portas que permanecem abertas após a troca de seus estados.
2. **Esquerda, Volver!** — Determinação da direção final após uma sequência de comandos.
3. **Suco de Acerola** — Cálculo do volume de suco, em litros, dividido igualmente entre os amigos.
4. **Help!** — Cálculo do placar de uma competição, considerando os problemas resolvidos e as penalidades por tentativas incorretas.

Cada desafio possui uma pasta própria com os seguintes arquivos:

- Arquivo `.py` com a solução em Python.
- `entrada.txt` com os dados de entrada.
- `saida.txt` com os resultados.
- `README.md` com a descrição do desafio e a lógica utilizada.
